### Projects

**[TimberCut Optimizer](https://github.com/DRencsok/TimberCutOpt)** · *in progress*

A Django REST Framework API that plans timber purchases. You enter the plank lengths and quantities you need, and it works out what to buy with minimal waste and cost.
The plan is to solve it first with a greedy algorithm, then with CP-SAT (Google OR-Tools), and compare the two.
