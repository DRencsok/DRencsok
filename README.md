### Projects

**[TimberCut Optimizer](https://github.com/DRencsok/TimberCutOpt)** · [Live API docs](https://timbercutopt.onrender.com/api/docs) · *v1.0*

Turns a construction cut list into a cutting plan that wastes as little timber as possible. This is the one-dimensional cutting stock problem, which is NP-hard. It offers two solvers and a benchmark comparing them:

- **Greedy (First-Fit Decreasing):** under 20 ms even at 500 pieces.
- **CP-SAT (Google OR-Tools):** an exact constraint model. It cut waste to 4.2 % vs 9.8 % for greedy on 10-piece jobs.

Use it from the CLI or the REST API (Django REST Framework, OpenAPI docs).It is Dockerized and deployed on Render.
